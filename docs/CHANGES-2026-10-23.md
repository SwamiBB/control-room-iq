## Design rules these changes implement

1. **Schedule on play-time, display match clock.** Every event and packet carries `play_ms` (monotonic from
   first kickoff, no stoppage time ambiguity) and `{period, clock_ms}` for display. All interval arithmetic
   uses `play_ms`.
2. **The gate is mandatory and structural.** AI-written text reaches a screen only inside an `OverlayPacket`
   that carries `approval_id`, `approved_by`, `approved_at`. The renderer refuses packets without them.
   There is no auto-approve path in the API. The SLA timer holds, never approves.
3. **Cues are code, captions are AI.** The deaf-fan strike cue (`FanCue`) is deterministic, contains no
   generated text, and is published immediately on `shot_taken` (≤ 1 s). The caption (`FanCard`) is
   generated text and is published only after the operator's decision on the matching proposal.
4. **Scheduling is code, content is AI.** The producer agent proposes layer, line, and payload; the
   `scheduler` module (plain Python) assigns `t_in/t_out`, resolves collisions, applies the one-story-per-
   window rule and goal/red-card preemption, and computes `hold_advice` from `pressure_trend`.
5. **Model choice is visible.** Three router deployments (`router-quality`, `router-balanced`,
   `router-cost`); each agent is bound to one; the served model from `response.model` is written to the
   span and to the output record (`model_served`).
