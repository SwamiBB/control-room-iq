## What is in this folder

- **preliminary-solution-description.md** — pre-build-week scoping draft (Oct 20). Dropped scope included
  Arabic and audio-description. See the superseded block at the top of that file.
- **PROJECT-SUMMARY.md** — Oct 23 team entry point with status, decisions and a document index.
  Reflects the state at that date; some rows are now stale.
- **PLAN.md** — build-week role assignments and day-by-day plan (Oct 20–27). Mentions deliverables
  that were later dropped from scope (Speech, Logic Apps approval).
- **CHANGES-2026-10-23.md** — change log for the v0.2 contract decided on Oct 23.
- **HANDOFF-\*.md** — six individual task handoff documents between team members (agents, web, fan
  card, goal routine metrics, match intelligence).

If you want to understand *how the submission was built*, read these. If you want to understand *what
the submission is*, use the top-level documents linked above.
