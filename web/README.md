# web

Operator console (`/operator`) and viewer (`/viewer`). `npm run dev`, `npm test`, `npm run build`.

**Don't keep this repo in a OneDrive-synced folder.** `node_modules` contains `.exe` files that the tenant
refuses to sync, which leaves OneDrive in a permanent error state. Sync has also served stale reads and
restored older copies over committed files. Clone to a local path such as `C:\dev\control-room-iq` instead.
