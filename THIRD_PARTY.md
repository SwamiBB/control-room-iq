# Third-party software

Control Room IQ is our own code, released under the [MIT licence](LICENSE). It contains no code taken from any
commercial product, and no real match, tracking or broadcast data: every match, club, player and venue in
`data/` is synthetic, generated by `services/simulator`.

It is built on open-source libraries, used unmodified and installed from PyPI and npm at build time. None is
vendored into this repository. Every library our code imports or bundles is under a permissive licence (MIT,
Apache-2.0, BSD, ISC, PSF, Unlicense), a font or data licence (OFL-1.1, CC-BY-4.0), or weak, file-level copyleft
(MPL-2.0) on files we don't change. None of those libraries is under GPL, LGPL or AGPL. The container base images
are a separate matter: their operating-system packages include GPL and LGPL software (see
[Container base images](#container-base-images)).

Versions are the ones installed on 2026-10-27 from `pyproject.toml` and `web/package-lock.json`, on Python 3.12
and Node 22 as in CI and the images. The images resolve the same version ranges at build time, so patch versions
there can be newer.

## Azure and Microsoft services

The deployed app calls Microsoft Foundry (models, Agent Service, evaluations), Event Hubs, Cosmos DB,
Container Apps, Storage and Application Insights. These are cloud services used under the Azure subscription
terms, not software we redistribute.

## Regenerating this file

```powershell
pip install pip-licenses
pip-licenses --from=mixed --format=markdown --with-urls   # in the project .venv
cd web; npm ci; npx license-checker --summary; npx license-checker --production
```

Update the tables when a dependency is added to `pyproject.toml` or `web/package.json`.
